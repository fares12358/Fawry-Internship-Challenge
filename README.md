## 📦 Project Description

This project is a basic console-based e-commerce system written in Java.  
The program simulates a shopping cart and checkout process with some simple business rules.

---

## ✅ Features

- Define products with name, price, quantity
- Some products can expire (e.g., Cheese, Biscuits)
- Some products require shipping with weight (e.g., Cheese, TV)
- Digital products (e.g., Scratch Cards) do not require shipping
- Add products to cart with quantity check
- Checkout process includes:
  - Subtotal calculation
  - Shipping cost
  - Total amount
  - Customer balance check and deduction
  - Shipment notice for shippable items
- Error handling for:
  - Expired products
  - Out-of-stock items
  - Empty cart
  - Insufficient balance
